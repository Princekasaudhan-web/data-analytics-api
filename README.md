# 📊 Data Analytics API

A RESTful API built with Node.js, Express.js, and MongoDB that demonstrates MongoDB Aggregation Pipeline for analytics.

## Features

- CRUD Operations
- MongoDB Aggregation Pipeline
- Group Posts by Category
- Total Views
- Average Views
- Top Viewed Posts
- Monthly Analytics
- Analytics by User
- Analytics by Date Range
- Dashboard Analytics
- REST API

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- Postman
